# 🤖 JARVIS ROADMAP

> "One step at a time."

# 🚫 Before Starting A New Feature

Ask yourself:

1. Is the current milestone finished?
2. Is this idea already in Future Ideas?
3. Will this move Jarvis closer to Version 1.0?
4. If not, add it to Future Ideas and continue.

# 📌 Project Rules

1. Finish the current milestone before starting a new feature.
2. Every new idea goes to "Future Ideas".
3. Every completed milestone:
   - Git Commit
   - Git Push
   - QA
4. Keep Jarvis stable.
5. Don't sacrifice stability for speed.

# 🧠 Design Philosophy

Jarvis is not just a chatbot.

Jarvis should:

- Remember.
- Learn.
- Assist.
- Tell the truth.
- Challenge the user when necessary.
- Never manipulate.
- Help the user achieve their own goals.
